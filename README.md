# RAZE CRMP PROJECT BUILDER

Это MVP-конструктор VK-бота: получает параметры проекта, проверяет FTP/MySQL,
разворачивает серверный шаблон и патчит известные URL в APK-шаблоне.

## 1. Что положить в template/

`template/crmp/` — распакованный серверный шаблон из вашего архива.

Нужны как минимум:
- gamemodes/
- plugins/
- scriptfiles/
- server.cfg
- bd.sql

`template/launcher-template.apk` — ваш APK-шаблон. Файл большой, поэтому его не следует коммитить в обычный Git-репозиторий.

## 2. Переменные Bothost

Создайте:
- VK_TOKEN — токен группы VK
- OWNER_IDS — VK ID владельца через запятую
- KEYSTORE_PASSWORD — пароль ключа подписи APK

## 3. Запуск

Bothost поддерживает Dockerfile и переменные окружения; после подключения Git репозитория деплой выполняется автоматически. Не храните токены в коде.

## 4. Важное ограничение APK

В переданном APK найдены жёстко зашитые URL:
- https://ragerussia.online/
- https://vizirs-shop.online/
- https://vizirs-shop.online/client/

Патчер изменяет эти строки внутри DEX и пересобирает подпись APK. Это не заменяет полноценную разработку собственного лаунчера: нативные библиотеки и package name пока не меняются.

## 5. Команды

/create — начать мастер создания
/status — состояние
/cancel — отменить
/help — помощь

Для продакшена рекомендуется добавить SFTP, очередь задач, отдельную БД конструктора,
проверку запуска сервера и отправку готового APK документом VK.
